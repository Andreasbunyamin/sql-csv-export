# Put the Kaggle data here

Download **Walmart.csv** from
[Walmart Dataset by M Yasser H](https://www.kaggle.com/datasets/yasserh/walmart-dataset) on Kaggle
(a free account is needed) and save it in this folder. The zip that Kaggle downloads works too.

Then run `load_demo_data.bat` (Windows) or `.venv/bin/python demo/load_walmart.py` (macOS / Linux).

The dataset is released under CC0: Public Domain. The data file is not part of this repository,
and Git ignores this folder, so nothing you put here is pushed by accident.
